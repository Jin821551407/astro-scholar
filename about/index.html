关于我

阿劲的数字工坊

一名热爱构建与分享的全栈开发者，主要使用 TypeScript / Node.js 与 React / Vue 技术栈。日常写业务代码，业余折腾 side project、 开源工具与这个博客。相信好代码应该可读、可测、可维护， 也相信把踩过的坑写下来，比独自再踩一遍更有价值。

开发理念

「先让它跑起来，再让它跑得好，最后才考虑让它跑得炫。」

技术栈

  • 前端 TypeScript、React、Vue 3、Astro、Tailwind CSS。 关注组件设计、性能优化与可访问性，偏好类型安全与清晰的模块边界。
  • 后端 & 工具 Node.js、Express、PostgreSQL、Redis。 熟悉 RESTful API 设计，也用过 Serverless 与 GitHub Actions 做自动化。
  • 工程化 pnpm、Vite、Docker、CI/CD。 重视 lint/test 流水线、Monorepo 管理与可复现的构建环境。
  • 正在学习 Rust（系统工具方向）、LLM 应用开发、WebAssembly。 技术选型上倾向「够用就好」，但会对感兴趣的方向深挖。
